# HackRL 실험 결과 및 연구 진행 보고서

2026-10-02 · Asia/Seoul · 보고 범위: 기존 Craftax 개발 실험부터 TICK-CLAIM 목표 묶음 비교와 seed 10 붕괴 진단까지

## 1. 현재 결론과 다음 연구 단위

TICK-CLAIM에서는 정상 환경에서 배운 다목표 이력이 이후 mutant 적응의 결함 활용을 촉진했다. 목표 전용 사전학습으로 정상 납품을 배운 것만으로는 같은 수준의 활용이 나타나지 않았다. 활용 정책은 같은 정책을 정상 커널에 넣었을 때보다 결함 커널에서 목표를 더 빨리 달성했고, 실제 에피소드별 할인 return에서도 이득이 확인됐다.

목표 집합을 분해한 최신 비교에서는 재고·미성숙 목표 묶음 M과 나머지 정상 목표 묶음 N을 함께 넣었을 때 큰 활용이 나타났다. 최종 자연 시작 mode 초과 납품률 차이는 D 7.5%, D+M 15.0%, D+N 0%, D+M+N 74.4%였다. 이는 해당 학습 계약의 결합 효과를 지지하며, 특정 목표나 내부 표현을 원인으로 식별한 결과는 아니다.

결합 조건 seed 10은 사전학습 때 정상 납품을 완전히 수행했지만 mutant 적응 도중 수확·예약·납품 행동이 사라졌다. 같은 출발점의 fixed 계속 학습에서는 정상 수행이 유지됐다. 이 seed를 제외하지 않고 주 지표에 포함한다.

**진행 결정:** TICK-CLAIM의 목표별 제거·추가, 폭·entropy 및 붕괴 원인 추가 스윕은 여기서 종료한다. 다음 연구 단위는 PACK-RESTORE의 커널·정상 경로·독립 oracle·실제 활용 이득 검증이다. 이후 별도 결함에서 무사전학습/목표 전용/다목표 이력의 핵심 비교를 반복한다. 알고리즘과 훈련량·파라미터 수의 본격 비교는 여러 결함에 공통으로 적용할 평가 계약을 마련한 뒤 진행한다. 이 보고서 작성은 새 학습 실행을 뜻하지 않는다.

## 3. 과제·결함·측정 정의

### TICK-CLAIM

작업장은 16×16, 시간 제한 H=128이며 생존 감소와 몹이 없다. 작물 한 성장 주기당 정상 지급은 곡물 1개다. 예약 수확은 delay 2/3/4 뒤에 처리된다. 예약이 만료하는 틱에 수동 DO와 예약 정산을 겹치면 mutant는 같은 주기에 곡물 2개를 지급한다. fixed는 수동 처리 뒤의 청구 상태를 확인하므로 총 1개만 지급한다.

독립 oracle은 객체·세대·성장 주기당 지급량 ≤1이라는 불변식을 검사한다. 정책 관측과 목표 보상에는 oracle 위반·곡물 provenance·variant ID를 넣지 않는다. oracle은 커널·목표 보상과 분리됐지만 합성 fixture 및 작성자 맥락을 공유하므로 외부 실제 게임 재현 검증과 같지는 않다.

48 layout과 192 초기 상태, delay 2/3/4는 하나의 결함 메커니즘의 변형이다. 검증된 Easy/Medium/Hard 발견 난도 등급이 아니다. 커널 단계의 보고된 검증은 정상·결함 trace와 7개 음성 대조군, 512-worker CPU eager/JIT/vmap 검사, 집중 테스트 43개 및 당시 전체 테스트 112개 통과였다. 후속 GC 보정 단계의 저장소 문서는 126개 테스트 통과를 기록한다. 이는 각 당시 버전의 검사 결과이며 이번 문서 커밋에서 테스트를 재실행한 결과가 아니다.

정상 참조 경로는 25 step, mutant 참조 경로는 delay에 따라 18/19/20 step이다. 학습 정책의 커널 간 길이 차이가 이 5~7 step보다 크더라도 정상 최적 경로 대비 이득으로 해석하지 않는다.

### 평가와 주 지표

- `mode`: 정책 분포의 argmax 행동. `sample`: 분포에서 뽑은 행동. 목표는 `deliver_3`, canonical ID는 `delivery/count_ge_3`이다.
- 자연 시작과 정상 prefix로 준비한 common setup을 별도로 집계한다. mode 자연 평가는 최근 비교에서 정책당 32 episode다. sample은 평가 계약에 따라 반복 수가 다르므로 별도 표의 분모를 따른다.
- 목표 성공, oracle 위반, 반복 위반, 초과 곡물 납품은 서로 다른 사건이다.
- 최근 이력·목표 집합·M/N 비교의 주 지표는 **mutant 환경에서 평가한 mutant 적응 정책의 초과 곡물 납품 episode 비율 − 같은 출발점에서 fixed를 계속 학습한 정책의 같은 비율**이다. 두 정책 모두 mutant에서 평가하는 대조다.
- 같은 정책을 fixed/mutant 커널에 넣는 비교는 결함의 정책별 총 효과를 측정한다. 서로 다른 두 정책을 같은 커널에서 비교하는 값과 구분한다.
- 기회 노출은 만료 예약·성숙 작물·객체/주기 일치·방향 등의 상태 조건이며 DO 선택 자체를 포함하지 않는다. 그러나 정책이 만드는 내생적 상태이므로 조건부 활용률만으로 원인을 식별할 수 없다.
- learner seed별 평균을 쓰고 실패 seed를 포함한다. 평가 episode나 checkpoint는 독립 학습 seed로 세지 않는다. 최종 checkpoint와 중간 최대값을 바꾸어 쓰지 않는다.

### 기존 Craftax 트랙에서 배운 점

Easy seed 0의 R-E/B-E mutant는 성공·위반률 1이고 fixed는 성공 0이었다. L-E는 fixed도 정상 3-step으로 성공했다. R-E 12셀에서는 기존 fixture fixed seed 1·2가 정상 경로를 학습했고 seed 0은 실패했다. 보충 fixture fixed는 세 seed 모두 평가 실패·소진 후 복구 성공 0이었다. 목재 소진을 실패의 유일한 원인으로 식별하지 못했다.

R-M fixed 세 seed는 시간 제한 H=512가 아니라 338 step에 사망했다. mutant 세 seed는 무철 제작과 공유 다이아몬드 구간을 3 step에 완료했다. D1에서 곡괭이를 가진 채 다이아몬드 앞에 두면 세 seed 모두 DO를 배웠지만 원래 reset에서는 실패했다. 이는 후반 배선의 작동을 확인하며 전체 정상 능력의 동등성을 증명하지 않는다. 기존 E/M/H는 발견 난도 사다리로 사용하지 않는다.

## 5. TICK-CLAIM 기본 능력과 초기 적응

workshop12 fixed 사전학습 세 seed는 각각 512 update, 16,777,216 전이를 완료했다. 합계 50,331,648이며 폭 512의 기록된 파라미터 수는 2,640,181이다. 당시 최종 `deliver_3` 검증 probe는 mode 61/64, 64/64, 64/64, sample 253/256, 256/256, 256/256이었다. 이 probe를 12-goal 능력 표로 대신하지 않았다.

후속 15-checkpoint 평가에서 자연 시작 기준 inventory 1/2/3, 시설 인접, 예약 있음, 미성숙 작물, 납품 ≥1/≥3의 측정 가능한 목표는 update 256부터 세 seed 모두 mode 성공률 1이었다. update 512의 자연 `deliver_3` 길이는 32.1/32.0/32.5였다. common setup의 seed 0은 29/32로 취약성이 남았다.

예약 없음은 모든 시작 상태에서 이미 참이라 유효 능력 분모 0이었다. 성숙 작물은 update 0부터 8-step 대기로 성공하므로 학습된 조작 능력의 증거가 아니다. checkpoint 복원 검사 15개는 실행 보고상 통과했지만 처음 공유 파일에는 동시 쓰기로 seed 1·2의 10개만 남았고 seed 0 근거는 프로세스 로그에 있었다. 이후 seed별 검사 파일로 분리됐다.

35쌍 모두 적응 전 mode 자연 차이 0, 최종 fixed 계속 학습 정책의 mutant 자연 위반 0이었다. sample 평가도 사전학습 512는 64.7%, 폭 1024는 96.1%, 사전학습 0은 2.5%로 mode와 방향이 같았다. 사전학습 0의 common 성공은 mutant 61.9%, fixed 70.0%여서 자연 성공 100%만으로 모든 시작 분포의 능력이 동등하다고 하지 않는다.

사전학습 128과 512의 평균은 비슷하고, 폭 256이 512보다 높았다. 따라서 사전학습량·모델 크기에 대한 단조 법칙은 지지되지 않는다. 폭 1024의 높은 수치는 후속 확인 없는 탐색 결과다. 반복 위반은 기준 조건 seed 2에서만 15.6%였으며 대부분 한 episode에 초과 곡물 1개를 얻는 활용이었다.

## 8. 예약 목표 집합 40셀과 사전학습 행동

seed 10–14. A=`deliver_3`, R=예약 있음/없음 두 목표, B=workshop12에서 R을 제외한 10개 목표, B+R=전체 12개 목표다. fixed 사전학습 512 update 뒤 두 커널에서 각각 4096 update 적응했다.

실행된 sampler는 허용된 목표 중 현재 거짓인 것을 선택하고 선택할 것이 없으면 자연 reset했다. 사전학습 성공 뒤 비활성 대기를 하지 않았다. 예약 목표가 있는 조건은 모두 거짓일 때 각 예약 목표 확률이 1/12가 되도록 가중치를 맞췄다. 이미 참인 목표 제외로 실현 빈도는 달랐다. 사전학습 20런 모두 valid=physical=16,777,216 전이였다.

| 조건 | 최종 자연 mode 차이 | 차이 >0 seed |
|---|---:|---:|
| A | 0% | 0/5 |
| A+R | 0% | 0/5 |
| B | 57.5% | 3/5 |
| B+R | 67.5% | 5/5 |

B의 seed별 값은 87.5/0/0/100/100%, B+R은 87.5/43.8/75.0/68.8/62.5%다. B+R−B는 평균 +10%p이지만 두 seed는 증가, 두 seed는 감소, 하나는 같았다. 균일한 예약 목표 효과로 해석하지 않는다. A/A+R은 여덟 checkpoint 모두 0이었다. 완료된 fixed 계속 학습 20셀의 최종 자연 초과 납품은 모두 0이었다.

### 20개 사전학습 checkpoint 동결 평가

만료 틱·한 틱 전·예약 없음 probe에 같은 `deliver_3`를 주면 A/A+R의 만료 틱 mode DO는 0/5, B/B+R은 모든 probe에서 5/5였다. 이는 사전학습 때 일반 수확 선택이 준비됐고 만료 타이밍 선택은 아직 갈리지 않았다는 관찰이다. mode DO 선택 빈도 0을 softmax 확률이 수학적으로 0이라고 바꾸어 쓰지 않는다.

512 worker ×128 step =65,536 결정 동안 목표 성공 뒤에도 `deliver_3`를 다시 켜 둔 동결 rollout의 수동 수확 횟수다. 이것은 사전학습 도중의 수확 횟수가 아니다.

| 조건 | seed 10 | 11 | 12 | 13 | 14 |
|---|---:|---:|---:|---:|---:|
| A | 0 | 0 | 0 | 1,600 | 0 |
| A+R | 0 | 0 | 0 | 0 | 0 |
| B | 1,984 | 3,456 | 2,256 | 4,032 | 3,632 |
| B+R | 960 | 1,600 | 2,208 | 560 | 1,296 |

A seed 13만 예약 없는 probe에서 DO였다. A+R은 ARM 16,736~43,408회로 예약을 만들지만 수동 수확을 선택하지 않았다. 학습 중 명령 목표 성공은 B/B+R에만 재고·작물·인접 목표 기록이 있었다. A/A+R은 그 목표를 명령하지 않았으므로 해당 집계의 0을 상태 미방문이나 능력 부재의 증거로 쓰지 않는다. 목표 성공은 명령 구간의 predicate 달성이며 상태 방문 횟수가 아니다.

## 9. M/N 제거·추가 40셀: 결합 효과

같은 목표 집합 계약에서 R은 제외하고 두 묶음을 나눴다. 모든 정책의 goal 표현은 같은 12차원이다.

| 기호 | 목표 | canonical index |
|---|---|---|
| D | 납품 ≥3 | 11 |
| M | 재고 ≥1/≥2/≥3, 미성숙 작물 | 0, 1, 2, 9 |
| N | 작물·예약장치·납품처 인접, 성숙 작물, 납품 ≥1 | 3, 4, 5, 8, 10 |

M은 수확 결과와 관련된 묶음이며 수동 수확 전용 목표가 아니다. 예약 정산으로도 달성할 수 있다. D+M+N의 목표 집합은 이전 B와 같다. 사용자는 두 실행이 같은 학습 계약임을 확인했다. 별도 실행 결과를 평균 개선으로 해석하거나 같은 seed 번호의 재실행을 독립 seed처럼 합치지 않는다.

### 최종 자연 시작 mode, adaptation 4096

| 조건 | seed 10 | 11 | 12 | 13 | 14 | 5-seed 평균 | >0 seed |
|---|---:|---:|---:|---:|---:|---:|---:|
| D | 12.5% | 0 | 25.0% | 0 | 0 | 7.5% | 2/5 |
| D+M | 37.5% | 0 | 37.5% | 0 | 0 | 15.0% | 2/5 |
| D+N | 0 | 0 | 0 | 0 | 0 | 0% | 0/5 |
| D+M+N | 0 | 96.9% | 87.5% | 87.5% | 100% | 74.4% | 4/5 |

fixed 계속 학습 20셀은 최종 자연 초과 납품 0이므로 이 차이는 mutant 적응 정책의 초과 납품률 자체다. 조건부 초과 납품은 기회가 관측된 episode에서 모두 1로 보고됐다. 최종 조건 차이는 기회 노출과 함께 나타났지만, 이것만으로 학습 과정 전체의 병목을 기회 형성으로 식별하지 않는다.

32-episode 격자에서 96.9%는 31/32, 결합 평균은 74.375%다. 평균 효과는 다음과 같다.

- D에 M 추가: +7.5%p.
- D+N에 M 추가: +74.375%p.
- D에 N 추가: −7.5%p.
- D+M에 N 추가: +59.375%p.
- 차이의 차이 `(D+M+N − D+N) − (D+M − D)`: **+66.875%p**.

이는 다섯 seed의 기술적 상호작용 추정치다. 유의성·모집단 법칙·내부 능력의 필수 결합을 주장하지 않는다. seed별 상호작용은 −25.0/+96.875/+75.0/+87.5/+100.0%p로 균일하지 않다. 실패한 seed 10을 그대로 포함한다.

D는 2048의 2.5%부터 최종 7.5%, D+M은 128의 약 3.8%부터 최종 15%, 결합은 512에 약 71.2%로 올라 최종 74.4%였다. D+N은 여덟 checkpoint 모두 0이다. D+M에서 증가한 seed는 D에서도 활용이 있던 10·12였다. common setup에서 D+M seed 10은 100%여서 그 정책의 자연 시작 접근 과정에 제한이 남는다.

### 사전학습 능력과 행동 경로

20개 사전학습 모두 valid=16,777,216 전이, 빈 minibatch 0이었다. 만료 틱 제공 시 mode DO는 D 1/5(seed 14), D+M 2/5(seed 10·12), D+N 0/5, 결합 5/5였다. 학습 중 수동 수확 선택은 결합 조건 각 seed 약 90만~110만 회, D+N 2천~5천 회, D+M seed 10·12는 32만/42만 회이고 나머지 약 3천 회였다. 이전 목표 집합 동결 rollout 수확 횟수와 집계 기간이 다르다.

자연 `deliver_3` 32경로에서 D는 seed 14만 32/32, D+M은 28/32~32/32이고 예약 정산을 많이 사용했다. D+N도 대체로 32/32였지만 수동 수확은 0이었다. 결합 조건은 다섯 seed 모두 32/32였고 수동 수확과 예약을 함께 사용했다.

정상 납품 능력만으로 활용 차이를 설명하기 어렵다. 수확 선택도 필요·충분 조건으로 확인되지 않았다. D seed 14는 사전학습 만료 probe에서 DO지만 최종 활용 0이고, D seed 10은 probe에서 DO가 아니었지만 적응 뒤 12.5%를 보였다. 결합 seed 10은 수확을 선택했지만 최종 납품 자체에 실패했다. 특정 probe의 선택과 이후 학습 능력을 동일시하지 않는다.

큰 활용을 보인 결합 seed 11–14는 최종 mutant 자연 성공률 1, 길이 22~23이었다. seed 10은 성공률 0, 길이 128이었다. 이전 B 평균 57.5%, 3/5와 이번 74.4%, 4/5는 별도 실행이다. 이전 seed 10의 87.5%와 이번 0은 같은 계약 안의 재현 불안정 사례로 보존한다. 같은 계약이라는 보고만으로 GPU 실행의 byte-level 결정성을 주장하지 않는다.

## 10. 결합 seed 10: 정상 수행의 급격한 소실

사전학습 정책은 자연 `deliver_3` 32/32, 길이 28, 수동 수확 평균 2.1, 예약 생성 0.9였다. mutant 적응 1792까지도 32/32, 길이 28, 수동 수확 1.9, 예약 생성 1.1을 유지했고 mode/sample 모두 성공률 1이었다.

| 시점 / 자료 | mutant 적응 정책 | 같은 출발점의 fixed 계속 학습 |
|---|---|---|
| 사전학습 끝 | 자연 납품 32/32 | 공통 출발 정책 |
| 512 동결 평가 | mode 0.94, sample 1 | 이 보고에 해당 값 미제공 |

2048의 실패 경로는 수확·예약 생성·납품 0이었다. 128 step 중 약 124 step이 이동, 약 3.8회가 ARM이었다. ARM 선택과 실제 예약 생성은 구분한다. 4096에서는 ARM도 없어지고 128 step 모두 이동했다.

학습 로그의 급감 구간은 update 2001–2003이며, 동결 정책의 정상 수행은 1792까지, 완전 실패는 2048에서 확인됐다. 저장된 정책만으로 붕괴의 정확한 update를 2001 또는 2003으로 지정하지 않는다. mode와 sample, 두 커널에서 모두 실패하므로 mode 선택만의 문제나 결함 제거 때문에 생긴 실패라는 설명은 약하다.

이 실행에서 붕괴는 mutant 적응 분기에만 관측됐다. 최적화 불안정·행동 선호 고착·상태 분포 변화 등의 원인은 분리하지 못했다. 특정 PPO 구성 요소나 결함 자체의 직접 원인으로 단정하지 않는다. 추가 원인 규명은 다음 연구 단위의 선행 조건으로 두지 않는다.

## 11. 해석의 범위와 연구 진행 결정

### 지지되는 범위

1. 정상 환경의 다목표 이력은 이번 TICK-CLAIM에서 높은 활용과 연결된다. 무사전학습·목표 전용 사전학습의 정상 성공만으로 차이를 설명하기 어렵다.
2. 이전 Adam 모멘텀이 높은 활용의 필수 조건은 아니다. 파라미터·환경·RNG가 보존돼 actor 단독 효과는 아니다.
3. 예약 목표 단독 추가는 높은 활용을 만들지 않았다. 예약 목표 제외 조건도 예약을 경험하고 활용했으므로 예약 경험 불필요를 뜻하지 않는다.
4. M/N 결합은 큰 활용과 정상 수동 수확·예약의 공동 사용을 준비했다. 어떤 목표·표현·경험이 매개하는지는 식별되지 않았다.
5. mutant 적응은 시간에 따른 수확 선택을 바꾸고 자연 시작에서 활용 기회를 만드는 정책으로 이어질 수 있다. 같은 정책의 커널 효과와 실제 할인 return이 이득을 뒷받침한다.
6. 후속 적응은 이미 확보한 정상 수행도 무너뜨릴 수 있다. 활용률과 정상 목표 유지율을 함께 보고해야 한다.

### 아직 주장하지 않는 것

일반적인 버그 이해·인과 추론, 보편적인 다목표 필요성, 모델 크기·훈련량의 단조 scaling 법칙, 실제 게임에서의 자율 발견, 검증된 난도 사다리, 새로운 알고리즘의 우위는 확인하지 않았다. 하나의 합성 결함과 소수 learner seed의 결과다. 정상 목표 구성의 개입은 명령 빈도·상태 분포·actor/critic을 함께 바꾼다.

### 다음 단계

- **현재 결과 동결:** 이 보고서와 기존 artifact를 보존한다. TICK-CLAIM 세부 제거·추가와 붕괴 원인 추가 재학습을 멈춘다.
- **PACK-RESTORE 구현·검증:** 구조 기록 복원과 포장 내용물 보존이 겹치는 별도 자원 보존 결함을 구현한다. 정상 경로, 결함 trace, 음성 대조군, 독립 oracle, 실제 목표 이득을 검증한 뒤 학습 가능 manifest를 확정한다. 현재 [설계 manifest](manifests/pack_restore_v1.json)는 `design_only`, `runnable=false`다.
- **독립 결함의 핵심 재현:** 무사전학습·목표 전용·다목표 사전학습을 같은 출발점의 fixed 계속 학습/mutant 적응으로 비교한다. 실패 seed를 포함하고 같은 정책의 커널 교차 평가를 유지한다.
- **후속 벤치마크 비교:** 여러 결함의 계약을 고정한 뒤 PPO/PPO-RNN/LEO와 예산·파라미터 수를 비교한다. 현재 GC-PPO는 LEO를 참고한 목표 학습 기준선이며 LEO all-goals 학습의 구현·재현 결과가 아니다. 난도는 실제 발견·활용 절차와 측정 결과를 바탕으로 부여한다.
